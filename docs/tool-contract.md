# Контракт Tool: `assess_work_item`

## Назначение

Проверить, достаточно ли конкретно поставлена задача WorkTrack для передачи
исполнителю и последующей объективной приёмки.

## Вход

Одна JSON-строка с объектом задачи:

- `title`: непустая строка;
- `description`: подробное описание результата;
- `acceptance_criteria`: массив проверяемых критериев;
- `priority`: `low`, `medium`, `high` или `critical`;
- `assignee`: имя или идентификатор исполнителя;
- `due_date`: дата срока в ISO-формате `YYYY-MM-DD`;
- `dependencies`: массив зависимостей, допускается пустой.

## Выход

JSON-строка. При успешно разобранном объекте:

- `status`: `ok`;
- `ready`: можно ли передавать задачу исполнителю;
- `score`: оценка полноты от 0 до 100;
- `findings`: найденные блокеры и предупреждения;
- `recommendations`: конкретные исправления постановки.

При ошибке входа:

- `status`: `error`;
- `code`: стабильный код ошибки;
- `message`: понятное исправление для следующего вызова.

## Безопасное поведение

Tool не обращается к сети и не изменяет WorkTrack. Невалидный JSON, неверный
тип корневого значения и неожиданные поля не должны выбрасывать исключение
наружу: результат всегда возвращается в одном JSON-формате.
