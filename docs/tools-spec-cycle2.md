# Спецификации инструментов цикла 2

## `search_codebase`

- Назначение: найти определения и использования символа в репозитории WorkTrack.
- Вход: `query` — непустая строка; `path` — относительный каталог; `limit` —
  целое число от 1 до 50.
- Выход: JSON с относительным путём, номером строки и коротким фрагментом.
- Ограничения: запрет абсолютных путей, `..`, `.env`, `.git`, бинарных файлов и
  результатов за пределами корня репозитория; жёсткий лимит общего размера.

## `read_file`

- Назначение: прочитать ограниченный диапазон строк найденного текстового файла.
- Вход: относительный `path`, `start_line >= 1`, `end_line >= start_line`, не
  более 200 строк за вызов.
- Выход: JSON с фактическим диапазоном и строками с номерами.
- Ограничения: после `resolve()` путь обязан оставаться внутри корня; запрещены
  `.env`, ключи, сертификаты, `.git`, бинарные файлы и симлинки наружу.

Самый опасный будущий инструмент — выполнение shell-команд: даже с рабочим
каталогом проекта он может прочитать секреты, изменить Git-состояние или
обратиться к сети. Его нельзя давать агенту без allowlist команд, лимитов
времени, изолированного контейнера и отдельного подтверждения на запись.
