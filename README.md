# WorkTrack AI Assistant

CrewAI-ассистент для проекта WorkTrack — системы управления техническими
заданиями и этапами клиентских работ.

Ассистент проверяет готовность постановки задачи до передачи исполнителю:
находит пропущенные обязательные поля, неоднозначные формулировки и риски
приёмки. Решение использует именно GigaChat API; Ollama оставлен только как
локальный резервный провайдер, переключаемый через `.env`.

## Что проверяет Tool

`assess_work_item` принимает задачу в JSON и проверяет:

- название и описание ожидаемого результата;
- проверяемые критерии приёмки;
- приоритет из словаря WorkTrack;
- исполнителя и срок;
- формат зависимостей;
- субъективные слова вроде «нормально», «удобно» и «как-нибудь».

Tool не обращается к WorkTrack API и ничего не записывает в основной проект.
Его можно подключить к CRUD задач, когда соответствующий endpoint появится.

## Запуск

Требуется Python 3.12 или 3.13. На Intel macOS `crewai==1.15.22` нельзя
установить нативно из-за отсутствующего wheel одной из транзитивных
зависимостей; используйте Linux-контейнер или CI.

```bash
cp .env.example .env
# заполнить GIGACHAT_CREDENTIALS в .env
uv sync --all-groups
uv run python -m ai.run_agent
```

Переключение на локальную модель не требует правки кода:

```dotenv
LLM_PROVIDER=ollama
OLLAMA_MODEL=qwen2.5-coder:7b
OLLAMA_BASE_URL=http://localhost:11434
```

## Проверки

```bash
uv run ruff check .
uv run pytest
```

Трассы реальных запусков сохраняются в `ai/traces/*.jsonl`. В Git попадают
только явно отобранные учебные трассы без секретов и персональных данных.
