# WorkTrack AI Assistant

Учебный AI-ассистент для проекта WorkTrack — системы управления техническими
заданиями и этапами клиентских работ.

Ассистент проверяет готовность постановки задачи до передачи исполнителю:
находит пропущенные обязательные поля, неоднозначные формулировки и риски
приёмки. Практика реализуется в ветке `feature/agent-tool-1`.
